# EE6483 Project 2

本仓库为 Private，仅仓库所有者与获授权协作者可访问。
三人协作完成猫狗分类、CIFAR-10 多分类和类别不平衡实验。当前处于项目启动阶段，训练脚本与依赖版本将在基础流程跑通后补充。

## 分工

- A：数据清单、公共训练流程、基础 CNN 和案例分析。
- B：预训练模型、参数与增强对比、猫狗测试集预测。
- C：CIFAR-10、多类别适配和至少两种类别不平衡处理方法。

## 待共同确认的五项

1. 框架：Python + PyTorch + torchvision；A 跑通后锁定依赖版本。
2. 数据与标签：老师提供的猫狗划分，cat=0、dog=1；共同确定全量或固定子集。
3. 协作与设备：每人分支，通过 Pull Request 合并；分别登记计算设备。
4. 公共约定：主种子 42；统一配置、逐轮日志、模型保存与代码接口。
5. 交接日期：约定 A 交付最小可运行流程和 README 的时间。

## 私有仓库协作

B、C 向 A 提供 GitHub 用户名，由 A 发送协作者邀请，接受后克隆本仓库。各自在任务分支开发并通过 Pull Request 合并，不直接修改 main。
建议任务分支：a/baseline、b/pretrained、c/cifar10。公共标签、数据划分或接口修改时，说明影响并同步三人。未经小组共同同意，不公开仓库，不对外分享代码。

## 文件管理

建议使用 configs/、src/、data/manifests/、runs/、report_assets/ 分别存放配置、公共模块、数据清单、本地运行结果和报告图表。
数据图片、课程讲义、作业原文、账号密钥、虚拟环境和模型权重不上传。代码不写死个人机器绝对路径。后续补充安装、训练、评估和预测命令。
